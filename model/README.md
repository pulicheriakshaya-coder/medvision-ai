
# 🩻 MedVision AI

## Chest X-ray Abnormality Screening

MedVision AI is a hackathon prototype for AI-assisted analysis
of chest X-ray images using a pretrained deep-learning model.

## 🚀 Features

- Upload chest X-ray images
- Automatic image preprocessing
- AI-assisted abnormality screening
- Multiple chest X-ray finding scores
- Simple and interactive Streamlit interface
- Educational medical-imaging demonstration

## 🧠 Technology Stack

- Python
- Streamlit
- PyTorch
- TorchXRayVision
- NumPy
- Pillow
- OpenCV
- Matplotlib

## 🔄 Workflow

Chest X-ray
→ Image Upload
→ Preprocessing
→ Deep Learning Model
→ Finding Scores
→ Screening Results

## ⚠️ Disclaimer

This project is an educational and hackathon prototype.
The model outputs are not a medical diagnosis and should not
be used as a substitute for evaluation by a qualified healthcare
professional.
